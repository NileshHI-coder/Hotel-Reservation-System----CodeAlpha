# Hotel Reservation System

A GUI-based Hotel Reservation System developed using Java Swing.  
This project allows users to search, book, manage, and cancel hotel room reservations with payment simulation and file handling support.

Developed as part of the CodeAlpha Java Programming Internship.

---

## Features

- Book hotel rooms
- Cancel reservations
- Search available rooms
- View all available rooms
- Room categorization:
  - Standard Room
  - Deluxe Room
  - Suite Room
- Payment simulation
- Booking details table
- File handling using File I/O
- Save bookings permanently
- Load previous bookings automatically
- GUI using Java Swing
